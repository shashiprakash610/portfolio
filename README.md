# Shashi Prakash — Portfolio

This is my personal portfolio website built with React, Vite, and Tailwind CSS.

## Live Demo
Check out the live site here: [https://shashiprakash610.github.io/portfolio/](https://shashiprakash610.github.io/portfolio/)

## Features
- **Portfolio Guide**: A local Q&A guide to my background and projects; no API key or generative AI.
- **Project Showcase**: Detailed view of my work in AI research and data engineering.
- **Terminal UI**: A modern, terminal-inspired design.
- **Visitor Counter**: Real-time visitor tracking using Cloudflare Workers.

## Setup
1. Clone the repository
2. Install dependencies: `npm install`
3. The portfolio guide needs no API key or backend (see CHATBOT_SETUP.md)
4. Run locally: `npm run dev`
